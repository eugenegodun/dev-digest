# client/specs

Behavior specs and contracts for `@devdigest/web` — the intended behavior of UI
flows and screens, independent of how they're implemented. Linked from
[CLAUDE.md](../CLAUDE.md); loads only when relevant.

A spec describes *what* a screen/flow should do (states, edge cases, acceptance
criteria) — the source of truth that tests and components are checked against.
